# Little Lake Fishing

A small, browser-based fishing game made with HTML, CSS, and JavaScript. No installation or external dependencies are required.

## Play

Open `index.html` in a web browser.

## Controls

- **Space** or **Cast a line**: cast your line; press again to reel it in.
- **Left / Right arrow keys** (or **A / D**): move your line to aim for fish.
- **Click or tap the pond**: aim your line at that spot.

Catch fish before the 90-second timer reaches sunset. Different fish are worth different point amounts.
